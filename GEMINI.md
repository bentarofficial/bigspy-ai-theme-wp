# Gemini coding-agent project instructions

Read and follow [AGENTS.md](AGENTS.md) and the development/release policy at the top of [docs/roadmap-vi.md](docs/roadmap-vi.md).

Develop continuously, verify the agreed changes, record short notes in `docs/PENDING-RELEASE.md`, then commit and push to the designated working branch. Verify the remote commit and report its branch/hash; never leave completed work only locally. Report a blocked push explicitly and respect branch protection. Package and publish a consolidated release only after owner approval; routine updates do not authorize release-facing documentation maintenance, version bumps, ZIPs, tags, Releases, old-release deletion, or deployment. See the shared policy for exceptions and the approval boundary.
