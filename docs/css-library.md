# BIGSPY · Thư viện CSS

67 tác vụ trong 10 nhóm dành cho website dịch vụ và bán hàng dùng BIGSPY Theme.

Bản 1.14.0 thêm tiêu đề sản phẩm 3 dòng, nút coupon theo màu thương hiệu và ẩn đồng hồ Countix layout 1 trong giỏ hàng/thanh toán. Hai lựa chọn tiêu đề 2/3 dòng thay thế nhau. Countix là tùy chọn tích hợp plugin, không bắt buộc cài plugin để dùng theme.

## Cách sử dụng

1. Cài/cập nhật BIGSPY Theme 1.3.0, mở Giao diện → Tùy biến → CSS bổ sung.
2. Thư viện nằm trên ô nhập CSS. Mở nhóm rồi tích tên tác vụ để xem trước. Bỏ tích để tắt.
3. Nhấn Đăng (Publish) để lưu. Nếu rời Customizer mà chưa lưu thì thay đổi chưa được áp dụng chính thức.
4. Dùng tìm kiếm có dấu/không dấu, Chỉ đang bật hoặc Tắt tất cả / Hoàn tác.
5. Xuất cấu hình theme để mang bộ lựa chọn sang website khác.

Các tác vụ mặc định tắt. Màu kế thừa từ cấu hình thương hiệu. Nút vuông/bo mềm/viên thuốc và ảnh phủ khung/hiện trọn tự thay thế nhau. CSS riêng vẫn giữ nguyên bên dưới; độ ưu tiên CSS, style inline hoặc !important có thể khiến một tác vụ không hiện rõ.

WooCommerce phải hoạt động để dùng nhóm bán hàng. Nhóm dịch vụ định dạng block BIGSPY tương ứng đã có trên trang. Không tự tạo nội dung, ảnh, đánh giá, tài khoản hay thay đổi chức năng thanh toán. Plugin/builder dùng HTML khác có thể cần CSS riêng.
