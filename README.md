## Overview

BIGSPY AI Theme WP is a multipurpose WordPress theme for business, service and WooCommerce websites. Build with editable blocks in the native WordPress editor, customize the header, footer and global styles, and add motion where it helps the design. **BIGSPY AI Designer** is an optional assistant inside WordPress for planning and editing pages, writing content and creating images.

### Quick start

1. Download `bigspy-ai-theme-wp-X.Y.Z.zip` from the [latest release](https://github.com/bentarofficial/bigspy-ai-theme-wp/releases/latest).
2. In WordPress, open **Appearance → Themes → Add New → Upload Theme** and install the ZIP.
3. Open **BIGSPY AI Theme → About** for the setup checklist. AI Designer can be connected later with a [Kyma API](https://kymaapi.com/?aff=BIGSPY-AI-Connect) key.

Requires WordPress 6.5+ and PHP 7.4+. The theme works without AI Designer or other required plugins.
